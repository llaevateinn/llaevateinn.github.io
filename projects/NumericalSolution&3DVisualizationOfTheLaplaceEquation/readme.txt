Task 1 - Numerical Solution of the Laplacian Equation (Python)


Description: 
This Python program computes a numerical solution of the Laplace equation
(u_xx + u_yy = f(x, y)) on a square domain. The program generates a .vtk file
that can visualize the 3D solution surface in ParaView. 


Requirements: 
- Python 3.x
- numpy
- matplotlib


How to run: 
1. Open the Python script. 
2. Adjust parameters if needed (grid size, boundary conditions, etc.).
3. Run the script.
4. A .vtk file (e.g., relaxation_2d.vtk) will be created in the working directory.


Visualization: 
Open the .vtk file in ParaView to view the 3D solution surface.
